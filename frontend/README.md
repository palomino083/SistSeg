# Frontend Sistseg (configurado para API remota)

## Instalación rápida
1. Copia esta carpeta `frontend` dentro de tu proyecto.
2. Configura la variable de entorno en Vite (si despliegas): `VITE_API_BASE_URL=https://tu-backend.onrender.com`
3. Instala dependencias y arranca:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
4. Abre en el navegador: http://localhost:5173
